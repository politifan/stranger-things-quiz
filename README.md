# Хокинс · Кто ты из «Очень странных дел»?

Неофициальный фан-тест на русском языке. В трёх главах — 15 оригинальных ситуаций и четыре варианта действий на каждую. Один из шести персонажей становится результатом, второй показан как ближайшее совпадение. В портрете есть сильная сторона, роль в команде и подсказка на трудный момент.

Ответы и прогресс хранятся в текущей вкладке. Можно вернуться к любому пройденному вопросу, обновить страницу, пройти тест заново или скопировать результат. Вопросы и портреты находятся в `quiz.json`.

## Запуск

Python 3.10+.

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m uvicorn main:app --host 127.0.0.1 --port 8000
```

В PowerShell активируй окружение командой `.\.venv\Scripts\Activate.ps1`. Затем открой [сайт](http://127.0.0.1:8000/).

## Пять переменных окружения

Все переменные опциональны. Без них тест проходит от первого вопроса до результата, а дополнительные блоки скрыты.

| Переменная | Что включает | Пример |
| --- | --- | --- |
| `TVMAZE_SHOW_ID` | Карточку сериала с годом премьеры и оценкой из внешнего API | `2993` |
| `SITE_ANNOUNCEMENT` | Объявление под обложкой | `Новая версия теста уже доступна` |
| `SITE_EVENT` | Сообщение над тестом | `Тематический вечер в пятницу` |
| `SITE_RESULT_NOTE` | Примечание под портретом | `Сравни свой результат с друзьями` |
| `SITE_CONTACT` | Контактную строку в подвале | `Связь: hello@example.com` |

Задай нужные значения до запуска сервера. Для Bash используй `export TVMAZE_SHOW_ID=2993`, для PowerShell — `$env:TVMAZE_SHOW_ID = "2993"`. Файл `.env.example` показывает имена всех параметров.

FastAPI загружает данные из [TVmaze API](https://www.tvmaze.com/api) по ID сериала, кэширует ответ и возвращает только нужные поля. Карточка содержит атрибуцию TVmaze. Данные TVmaze распространяются по [CC BY-SA](https://creativecommons.org/licenses/by-sa/4.0/). При недоступном API тест продолжает работать.

## Подсчёт

Ответ добавляет основной черте 3 балла и дополнительной 1 балл. При равенстве сравнивается число основных совпадений, затем вклад последних ответов в обратном порядке. Числа служат для ранжирования и не показываются как проценты сходства.
